# flask-selfheal: Self-Healing URLs for the Web
My slides for the [flask-selfheal](https://github.com/GovernmentPlates/flask-selfheal) talk at EuroPython 2026.

[![licensebuttons by-nc-sa](https://licensebuttons.net/l/by-nc-sa/4.0/88x31.png)](https://creativecommons.org/licenses/by-nc-sa/4.0)

This deck is a practical showcase of [flask-selfheal](https://github.com/GovernmentPlates/flask-selfheal) (MIT licensed), a Flask extension for automatically fixing broken URLs using chainable resolvers (partial string matching, fuzzy matching, and database-backed slug resolution).
